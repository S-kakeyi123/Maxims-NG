MAXIMS NIG LTD — PREMIUM CORPORATE WEBSITE
===========================================

This is a responsive, multi-page static website concept for MAXIMS NIG LTD.

PAGES
- index.html       Home
- about.html       About the company
- services.html    Services and registered capability areas
- products.html    Products and supply categories
- facilities.html  Facility image and infrastructure scope
- hse.html         HSE and sustainability
- projects.html    Projects and experience
- contact.html     Business enquiry page

BRAND DIRECTION
Graphite / dark shiny grey foundation, metallic yellow highlights and restrained red accents.
The temporary M monogram is a placeholder identity and can be replaced with the approved company logo.

IMPORTANT BEFORE PUBLISHING
1. Replace YOUR-COMPANY-EMAIL@example.com in assets/script.js with the official company email.
2. Add verified company phone number, email and office address to contact.html and footer if desired.
3. Confirm the facility photograph's correct description, location, ownership/operating relationship and permission to publish.
4. Add only verified licences, certifications, project records, client references and operational claims.
5. The contact form currently opens the visitor's email application; it does not submit to a server.
6. This package is a front-end website. It does not include a CMS, database, hosting, domain connection, user accounts or backend enquiry storage.

The website text intentionally distinguishes registered objects/business scope from proof of current operations, licences or completed work.
To preview locally, open index.html in a browser. Upload the entire folder to a static web host to publish.
